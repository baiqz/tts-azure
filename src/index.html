它是怎么做到"不限字数"的？ 文字会先按段落和句子切成小段，几段并行合成，再把音频按帧边界无缝拼成一条。所以一万字和一百字走的是同一套流程，只是段数不同 —— 不存在"字数上限"这回事。

通道说明：本工具走的是微软公开的语音合成通道，无需注册、无需密钥、不消耗你的任何额度，也不上传文字到第三方服务器。它是公开接口而非微软官方授权入口，可能随时失效；若要用于商业交付，建议改用 Azure 官方语音服务（正式 API + 你自己的密钥）。请勿用于违法或侵权用途。

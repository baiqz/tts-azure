# 文字转 MP3 · 云泽配音

把**任意长度**的中文文字转成一条 MP3。内置 **958 种**微软语音（中文 91 种），**含云泽**。
纯前端单文件，打开就能用 —— 不用装东西、不用注册、不用填密钥。

**在线地址：<https://baiqz.github.io/tts-azure/>**

---

## 一句话上手

打开上面的网址（或双击本仓库根目录的 `index.html`），把文字贴进左边的框，选音色，点「开始合成」。

有三种给文字的方式，随你顺手：

1. **直接粘贴**（Ctrl+V）
2. **点「读取文件」** —— 选 txt / Word / 字幕文件
3. **把文件拖到文本框上** —— 松手就读进来，可多选

离线使用：把 `index.html` 这一个文件保存到本地，双击即可，全程不依赖本仓库的其他文件。

## 三个核心点

### 1. 不限字数

文字先按**段落 → 句子 → 分句**三级边界切开，变成一堆互不依赖的小段；几段**并行**合成，
最后按 **MP3 帧边界**逐帧拼成一条完整音频。所以一万字和一百字走的是同一套流程，
只是段数不同 —— 不存在"字数上限"这回事。

实测：**7560 字 → 10 段 → 35 分 16 秒音频 / 12.1 MB，合成耗时 4.9 秒**。

拼接是**字节级**的（不重编码、不重新压缩），成品解码回来最长静音 0.92 秒（就是正常说话的停顿），
拼接缝没有产生任何空洞或爆音。

### 2. 云泽在内

走的是微软的语音合成通道，音色库取服务端**实时声库**，云泽（`zh-CN-YunzeNeural`）在列，
且支持它的全部 9 种情感风格（平静 / 愉快 / 严肃 / 沮丧 / 不满 / 愤怒 / 恐惧 / 悲伤 / 纪录片旁白）。

音色分类：

| 分组 | 数量 | 说明 |
|---|---|---|
| 推荐 | 8 | 云泽置顶，其后是晓晓、云希、晓伊、云健、云扬、Dragon HD 等 |
| 普通话 | 77 | 含龙系列 HD 高清音色、MAI-Voice 新模型 |
| 方言 | 7 | 辽宁、陕西、山东、四川、河南、广西 |
| 港澳台 | 6 | zh-HK / zh-TW |
| 多语言 | 59 | 一个音色跨语种念 |
| 高清 HD / 新模型 | 397 | Dragon HD / Dragon HD Flash / HD Omni / MAI-Voice |
| 全部语言 | 958 | |

**关于中文名的处理**：显示名优先采用微软官方数据里给的本地化名（`云泽`、`云希 四川`、`晓晓 多语言`）。
官方只给英文名的 HD / MAI 系列，用「拼音段 · 系列」拼（如 `Xiaoxiao2 · Dragon HD Flash`），
**不做人肉翻译** —— 宁可显示拼音，也不编一个可能错的中文名。

### 3. 免密钥

不需要 Azure 账号，不消耗任何额度，也不往第三方服务器上传你的文字。

## 读取文件

不用先复制粘贴到记事本再倒腾 —— 点「读取文件」或把文件直接拖到文本框上就行，**可多选**，多个文件按顺序拼成一篇。

| 格式 | 怎么处理 |
|---|---|
| `txt` `csv` `tsv` `json` `log` `ini`… | 自动判别编码：**UTF-8 / GBK / UTF-16 / 带 BOM** 都能正确读出来 |
| `srt` `vtt` `ass` `ssa` | 字幕：剥掉序号和时间轴，只留台词（块内折行会被合并成一句） |
| `html` `htm` `xml` | 网页：剥掉标签、脚本、样式、注释，只留正文 |
| `md` `markdown` | 清理排版标记：标题井号、粗体星号、链接语法、列表符号 |
| `docx` | Word 文档：解 zip 取正文；**修订删除的内容和域代码（页码之类）不会被读进来** |
| `pdf` `doc` | 读不了 —— 会明确告诉你原因和替代办法，不会静默读出一堆乱码来让你合成 |

细节说明：

- **GBK 是这条路上最大的坑**。Windows 上大量中文 txt 是 GBK 编码，不判别就是一屏「锟斤拷」。
  这里的顺序是：先看 BOM，再严格按 UTF-8 试一次，失败就按 GBK 解，再校验有没有残留替换字符。
- **docx 不引第三方库**。用浏览器原生的 `DecompressionStream` 解开 zip、取 `word/document.xml`，
  所以「一个文件搞定」这个前提没有被打破，产物依然是一个 HTML。
- **文本框已有内容时是追加**（接在后面），不会把你刚写的东西冲掉。想换一份就先点「清空」。
- 单文件上限 24 MB，可多选 —— 这是防呆（免得有人拖进来一个 500MB 的日志），不是能力上限。

## 界面上的东西

- **文本区**：字数 / 段数 / 预估时长 / 预估体积实时更新。预估时长会跟着语速走（设 -20% 就把时长拉长 1.25 倍）。
  「读取文件」按钮 + 拖拽落区（拖进来时会有整块高亮提示）。
- **音色区**：7 个分组 + 搜索（中文名、英文 ID、地区都能搜）+ 「显示更多」分页。
- **参数**：语速（-50% ~ +100%）、音调（-50 ~ +50Hz）、音量（-50% ~ +50%）、情感风格（随音色动态变化）。
- **高级设置**：每段字数（200 ~ 2000，默认 800）、并发数（1 ~ 6，默认 3）。
- **试听音色**：只合成开头 60 字，快速对比不同音色。
- 音色、参数选择会记在浏览器里，下次打开自动恢复。

## 开发

```bash
# 构建单文件（src/ → 根目录 index.html，含静态自检）
node tools/build.js

# 离线单测
node tests/run.mjs

# 真机端到端（本地服务）
node tools/e2e.mjs

# 真机端到端（双击 file:// 模式）
E2E_FILE=1 node tools/e2e.mjs

# 真机端到端（打线上，验证部署出去的那份文件真能跑）
E2E_LIVE_URL=https://baiqz.github.io/tts-azure/ node tools/e2e.mjs
```

> `tools/build.js` 是唯一的产物出口：`src/` 下的 8 个模块 + CSS 会被内联进根目录 `index.html`。
> **根目录 `index.html` 是构建产物，不要手改**，改 `src/`。

重新生成测试样本（改了 `fileloader.js` 想加用例时）：

```bash
python tests/gen_file_fixtures.py    # 造 GBK / BOM / UTF-16 文本 + 真 docx 到 tests/fixtures/
```

## 说明与边界

- **通道性质**：本工具走的是微软公开的语音合成通道（借翻译 App 的公开签名取临时 token，再打语音合成端点）。
  它**无需密钥、不消耗额度**，但属于公开接口而非微软官方授权入口，**可能随时失效**，届时页面顶部的通道状态会变红。
- **正式商用建议**：改用 Azure 官方语音服务（正式 API + 你自己的订阅密钥），云泽等音色在那边同样可用，
  免费层每月 50 万字符。本工具的 `src/azure.js` 只需替换取 token 那一段即可切换到官方密钥模式。
- **性能边界**：成品体积约 6 KB/秒音频。一百万字的文本会产生约 1.3 GB 的 MP3，浏览器内存会吃紧；
  实际使用建议单次控制在几十万字以内，或分批合成。
- 文字**不会**上传到除语音服务之外的任何地方；不写入任何日志。
- 请勿用于违法或侵权用途。
